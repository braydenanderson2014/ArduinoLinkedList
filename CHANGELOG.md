# Changelog

All notable changes to this library are documented in this file.

## 1.0.8

- Rewrote the README to document the current public API more clearly.
- Added a dedicated changelog for the standalone mirror repository.
- Aligned library metadata and repository links for the mirrored package.

## 1.0.7

- Fixed `getElement()` behavior for missing values.
- Added `add()` as an alias for appending to the list.

## 1.0.6

- Renamed the library files to `BasicLinkedList` to align the header and library name.

## 1.0.5

- Removed deprecated helper functions in favor of `contains()`.
- Renamed the removal API for clearer behavior.
- Added `getElement()` to return values instead of raw pointers.

## 1.0.4

- Added `getAsString()`.
- Deprecated older existence-check helpers in favor of `contains()`.
- Removed debug statements to reduce memory usage.
- Added function comments to the library.

## 1.0.3

- Added debug configuration helpers.

## 1.0.2

- Updated the README.
- Added overloaded insert support.
- Added iterator support.
- Adjusted the internal `Size` member naming.

## 1.0.1

- Fixed issues related to `getElement()`.
- Fixed packaging and build issues.

## 1.0.0

- Initial release.
